# Magic Word releases

## 0.3.0

- Cloudflare serves authenticated MCP and the browser console at one HTTPS origin. The installer creates an independent owner token and keeps the credential file owner-only.
- `npm run connect:host` verifies the online server before switching this checkout’s AI clients to production.
- Instagram owners can read live posts, comments and inbox activity. A local Composio connection can provide those reads while native Meta setup is pending. Both setup and reads verify the configured Instagram handle.
- YouTube supports public upload feeds and public comment reads with a restricted YouTube Data API key.
- Instagram's native webhook still requires Meta approval where applicable. TikTok Business Messaging requires its own access.

## 0.2.0

Released the local sample, production hosting instructions, authenticated MCP, Instagram flow automation and additional channel adapters. See the [release notes](https://github.com/paytonbilodeau/magic-word/releases/tag/v0.2.0).
