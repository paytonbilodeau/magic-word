# Magic Word

Run from the project root with Node 24 or 26. Use `npm ci`, `npm run typecheck`, and `npm test`. For an offline demonstration use `npm run preview` or the MCP stdio server. It shares the sample store with the browser.

The local default is synthetic. Ask the operator for the intended destination before provisioning hosting, connecting accounts or activating real sends. Store credentials in the host's private environment or owner-only credential file.

The Instagram engine and Cloudflare installer derive from FewChat. See [NOTICE.md](NOTICE.md). Node hosting is in [docs/SELF-HOST.md](docs/SELF-HOST.md). MCP transports and credentials are in [docs/MCP.md](docs/MCP.md). Additional channel bindings are in [docs/CHANNELS.md](docs/CHANNELS.md).
